# R5 semantic contract — W1 freeze

This document freezes the host/native contract used by the R5 outcome engine.
It implements the Architecture v3.2.2 rules; any protocol encoding is a later
W6 concern and must carry this schema version rather than infer defaults.

## Schema and arithmetic

- Schema version: `R5_SCHEMA_VERSION = 1`.
- `seq` is a unique, strictly increasing input ordinal.  Every
  integrity-checked input, including a capacity drop and S2, advances it.
- Primary population is exactly `S0 <= seq < S1`.  `S0` is included and `S1`
  is excluded.  `S2 = S1 + tail_blocks`; the default tail is 8 and the allowed
  minimum is 2.
- `nominal(seq) = epoch_cycles + (seq + 1) * block_period_cycles`.
- `deadline(seq) = nominal(seq) + deadline_cycles`.  The formal completion
  time is the caller-supplied logical `t_commit`.  A completion at equality is
  `ON_TIME`; a later one is `LATE`.
- Histogram width is `D / 16`; the 128 normal bins represent
  `[0, 8D)`.  A latency `>= 8D` goes to the overflow bucket.  Thus exactly
  `8D` is overflow; this is explicit and tested.

## Boundary and ordering rules

1. The input event first passes serial/integrity validation.
2. `S0` opens the CPU window before normal admission.
3. `S1` closes the CPU window before normal admission; its own normal
   admission belongs to TAIL, not primary population.
4. `S2` closes observation and sets the stop gate before any normal admission,
   capacity-drop or occupancy accounting.  It is raw-input diagnostic only.
5. The cutoff is sufficient only when `t_irq(S2) > deadline(S1-1) + epsilon`.
   Otherwise the result is `INSUFFICIENT_OBSERVATION`, distinct from an
   infrastructure/integrity failure.
6. The RuntimeEvent serial is the sole classifier for same-timestamp cutoff and
   completion races: the earlier serial wins.  A completion after a closed
   outcome is diagnostic-only and cannot change an outcome.

## Outcome and lifecycle rules

Every primary `seq` has exactly one immutable terminal outcome:
`CAPACITY_DROP`, `ON_TIME`, `LATE`, or `EXPIRED_UNRESOLVED`.  Prior to closure
an admitted block is `ADMITTED_PENDING`; it is not yet terminal.  At a
sufficient S2 all pending primary admissions become `EXPIRED_UNRESOLVED` in one
bounded pass.  Conservation at seal is:

`N_cohort = N_drop + N_on_time + N_late + N_unresolved`.

`OPEN -> OUTCOME_CLOSED -> SEALED` is one way.  SEALED output fields are
immutable.  Diagnostics arriving after cutoff are recorded in separately named
live counters and do not change sealed outcomes.

`p99_completed_by_cutoff` uses completed primary samples only.  The
all-admitted P99 is `CENSORED` whenever unresolved primary admissions exist.
No completed samples is `N/A`; a rank which lands in overflow is
`OUT_OF_RANGE`.

## Occupancy

Each ordinary admission attempt records the queue occupancy `Q` observed
immediately before the FREE/admission decision.  This is a count population,
not a time-weighted measure.  W6 must take it from the real queue adapter.
S2 creates no occupancy sample.

## Golden-vector identifiers

The stable vectors use the IDs `SYN01` through `SYN14`.  Their executable
definition is the native `synthetic` test suite introduced with W5; the
machine-readable counterpart is generated by the R5 host tool.  The required
coverage is boundaries, tail, cutoff races, equality/deadline, overflow,
P99/rank/censoring, result immutability, and run isolation.
